# PoliTech Politician Platform

A React + TypeScript prototype for the PoliTech politician side. This platform is designed for local and state politicians, featuring:

- CRM for constituent management
- Message and campaign communication tools
- Vault for FEC compliance, donations, and expenditure tracking
- Post generation and cross-posting workflows
- Zip code mapping and constituent visualization

## Setup

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Build production: `npm run build`
